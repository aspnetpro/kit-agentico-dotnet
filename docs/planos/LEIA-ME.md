# Planos

O comando `/plano` salva aqui o plano de cada feature, com as etapas em checkbox.

O arquivo do plano também é o **estado do trabalho**: se a conversa com o agente ficar longa demais, ou você precisar parar e voltar amanhã, abra uma sessão nova e peça para retomar a partir do plano. É mais confiável do que esperar que o agente "lembre".
